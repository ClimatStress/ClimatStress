Politique de confidentialité

Dernière mise à jour : 06/11/2026.

ClimatStress n'a ni compte, ni publicité, ni outil d'analyse d'usage. Le développeur ne reçoit pas vos données.

Données lues dans Apple Santé (avec votre autorisation) : date de naissance (pour calculer l'âge), FC au repos et FC en direct de votre Apple Watch pendant une séance de travail. Un entraînement est enregistré dans Apple Santé pour maintenir la séance active en arrière-plan.

Données saisies par vous : température de l'air, humidité, vent, rayonnement solaire, valeurs de Heat Index ou de WBGT, et vos réglages.

Localisation : si vous touchez le bouton météo, votre position approximative est envoyée à Apple Weather (WeatherKit) pour obtenir la météo locale. Les conditions de confidentialité d'Apple s'appliquent à cette requête. La position est aussi enregistrée sur votre appareil, au démarrage de la première séance du jour et lorsque vous touchez « Utiliser la position actuelle », pour imprimer les coordonnées du site dans votre rapport ; elle n'est jamais envoyée au développeur.

Stockage : toutes les données restent sur votre iPhone et votre Apple Watch. Les rapports (CSV, PDF) sont enregistrés dans le dossier ClimatStress de l'app Fichiers. ClimatStress n'écrit pas de données de santé dans iCloud ; si vous copiez vous-même un rapport dans iCloud Drive, cette copie relève de vos réglages iCloud.

Partage : rien n'est partagé avec des tiers. Vous décidez de partager ou non un rapport.

Conservation et suppression : les données sont conservées jusqu'à ce que vous les supprimiez. Réglages > Supprimer toutes les données efface les rapports stockés par l'app ; désinstaller l'app supprime ses données. Vous pouvez révoquer l'accès à Santé et à la localisation à tout moment dans Réglages iOS.

Achats : les abonnements et l'achat à vie sont traités par Apple (StoreKit). Le développeur ne reçoit ni vos données de paiement ni l'identité de votre compte Apple.

Accès gratuit : la date du premier lancement est conservée dans le trousseau de votre appareil pour calculer la période gratuite de 3 jours. Elle n'est envoyée nulle part.

Chat d'équipe (facultatif, version 2.0.0) : si vous l'utilisez, le nom que vous choisissez, vos messages et, uniquement si vous touchez le bouton de position, vos coordonnées sont stockés dans Apple iCloud (CloudKit) dans un groupe partagé par les personnes de votre chantier, et sont visibles de tous les membres du groupe. Le développeur n'exploite aucun serveur et ne peut pas les lire. Les messages sont masqués et supprimés par l'app après 48 heures (un message peut rester stocké plus longtemps si personne n'ouvre l'app). Apple utilise votre compte iCloud pour vous identifier ; l'app ne conserve qu'un identifiant pseudonyme dérivé de celui-ci. Vous pouvez signaler un message, bloquer une personne, quitter le groupe ou, si vous en êtes le propriétaire, le supprimer. Sans iCloud, ou si vous n'ouvrez jamais l'onglet Messages, rien n'est envoyé.

Enfants : ClimatStress s'adresse à des adultes en activité.
